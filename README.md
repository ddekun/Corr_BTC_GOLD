# Corr_BTC_GOLD
Проект на Python и pandas по анализу корреляции между Bitcoin (BTC) и Gold на исторических данных.

В ноутбуке загружаются два CSV-файла, очищаются и преобразуются значения цены открытия, приводятся к единому виду даты в двух источниках, после чего данные объединяются по общим датам и рассчитывается корреляция между BTC и Gold. В проекте отдельно проверяется, что часть дат не совпадает из-за разного календаря торгов, поэтому в анализ попадает только пересечение наблюдений. По итоговой объединённой выборке из 3143 строк рассчитана положительная корреляция цен открытия около 0.606.
